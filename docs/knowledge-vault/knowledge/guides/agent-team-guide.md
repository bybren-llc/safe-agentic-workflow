# SAFe ART Agent Team Guide

A pointer card, not a copy. `docs/guides/AGENT_TEAM_GUIDE.md` is 578 lines and is the long-form
account of how the eleven agent roles actually work together; this card exists so the graph can
route to it instead of paraphrasing it.

## What It Is Authoritative For

- The eleven-role table of responsibilities and key outputs.
- The per-role workflow narratives — what each role does, in order, on a piece of work.
- The escalation paths: who raises what to whom when a role is blocked.
- The integration of SAFe cadence with the Simon Willison agent loop.
- Agent coordination via session archaeology, its own idea and not documented elsewhere.

Sixteen H2 sections cover this ground, including Agent Philosophy, Common Workflows,
Evidence-Based Delivery, Key Principles, and Success Metrics.

## When To Read It

Read it when assigning work across roles, when defining the workflow for a role that does not yet
have one, or when resolving who escalates to whom. It is the guide you send a new team member to
after they have read the role card for the seat they are filling.

## Boundaries

It overlaps the root roster in [AGENTS.md](../root-docs/agents.md): this guide is the long form,
that file is the card. It is **not** the source for exit states or workflow gates — those resolve
to the roster and to the [Agent Workflow SOP](../sop/agent-workflow-sop.md). When the two disagree
about a gate, the SOP wins.

For the collaboration model underneath the roles, see
[Round Table Philosophy](../../methodology/round-table-philosophy.md); for role assignment
mechanics, [TDM Agent Assignment Matrix](../workflow/tdm-agent-assignment-matrix.md).
