# Round Table Philosophy (Doc)

A pointer card for the document, distinct from the concept that summarises its argument. The
324-line `docs/guides/ROUND-TABLE-PHILOSOPHY.md` is load-bearing for three unrelated things at
once, which is why several methodology concepts all resolve here for their canonical text.

## The Three Authorities

1. **The seven Round Table principles** — equal voice through collaborative problem-solving, each
   with an "in practice" clause. Summarised in
   [Round Table Philosophy](../../methodology/round-table-philosophy.md).
2. **Stop-the-line authority** — five categories that justify halting work, and the four steps for
   exercising it. Summarised in [Stop-the-Line Gate](../../methodology/stop-the-line-gate.md).
3. **The evidence requirements table** — eight evidence types, each marked Always, UI, DB, or
   Tagged. Summarised in
   [Evidence-Based Delivery](../../methodology/evidence-based-delivery.md).

It also carries the swimlane definition and the POPM approval sequence, neither of which has its
own concept.

## When To Read It

Read the source rather than the summaries when someone questions whether an agent may push back,
when deciding what evidence a specific ticket needs, or when onboarding a human whose only prior
experience of AI is the order-taker model. The three summaries are map-cards; the tables and the
category lists live only in the document.

## Why This Card Exists Separately

One document, three citing concepts, is a drift risk: each summary can age independently. This
card names the source once so that a change to the document has a single obvious place to be
recorded, and so the graph does not imply three sources where there is one.
