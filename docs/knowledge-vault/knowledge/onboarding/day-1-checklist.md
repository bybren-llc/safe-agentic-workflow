# Day 1 Checklist

This is a map-card. `docs/onboarding/DAY-1-CHECKLIST.md` is the source of truth — 622 lines, a
stated 2-3 hours — and it is organised by the clock rather than by the system.

## What It Is Authoritative For

The ordered, time-boxed first-day sequence, with a pass/fail validation at each step. Seven phases
are listed: Repository Setup (30 min), Agent Provider Setup (30 min), Tool Integration (30 min),
First Agent Workflow (45 min), Validation and Retrospective (15 min), then two optional phases —
Agent Teams Setup (20 min) and Dark Factory Setup (30 min). Troubleshooting and Success sections
close it out. Prerequisites: Claude Code or Augment Code, a Linear or Jira account with API access,
and a GitHub account with repository access.

## Why It Is Separate From Getting Started

[Getting Started](../guides/getting-started.md) covers the same ground organised by task — it
configures a repository. This checklist onboards a person. The distinction matters when you are
deciding which to hand someone: if the repo is already set up and a new engineer is joining, the
task-organised guide will read as a list of things already done, while the clock-organised one
still works because its unit is the reader's morning.

## How To Start It

Do not start by reading it. Start at
[Meta-Prompts for Users](meta-prompts-for-users.md), whose section 6 supplies the copy-paste prompt
that drives this checklist — the checklist is intended to be executed by an agent alongside you,
not worked through by hand.
